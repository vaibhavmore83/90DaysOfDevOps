# Linux Commands

## Process Management Commands

**ps -ef**
  - Print detailed overview of process status.

**top**
  - Display sorted information about processes.

**kill PID**
  - Kill a process specified with its Process ID, PID, which can be obtained with **ps** command.

---

## File System Commands

**ls -al**
  - List all hidden files and folders with detailed information.

**diff A B**
  - Compare two files A and B; outputs the difference.

**touch A**
  - Create an empty file A.

**wc A**
  - Display word count of A.

**mkdir temp**
  - Create a new directory **temp** inside the current directory.
    
---

## Networking Troubleshooting Commands

**ifconfig**
  - Display all network interfaces with IP addresses.

**ping host**
  - Send ICMP (Internet Control Message Protocol) echo request to host.

**dig domain**
  - Display DNS information for the domain.

**curl link**
  - Display the HTML source of the link.
